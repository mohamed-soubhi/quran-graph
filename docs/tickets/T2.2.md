# T2.2 — Constraints and indexes in Neo4j (agy)

**Goal:** the constraints and indexes listed in `docs/schema.md` ("Constraints and indexes") exist in Neo4j,
created by an idempotent script.

## Steps
1. `src/graph/schema.cypher`: one `CREATE CONSTRAINT … IF NOT EXISTS` / `CREATE INDEX … IF NOT EXISTS` per line,
   names `<label>_<property>_unique` / `<label>_<property>_idx`; full-text indexes `ayah_text_norm_ft`, `segment_text_norm_ft`.
2. `src/graph/apply_schema.py`: runs every statement of the file with `get_driver()`; logs each name.
3. `python scripts/tasks.py schema` runs it.
4. `tests/test_graph_schema.py` (skip if Neo4j unreachable, unless SMOKE_STRICT): apply twice (idempotent);
   `SHOW CONSTRAINTS` contains exactly the 13 unique constraints of the schema; `SHOW INDEXES` contains the 3 range indexes
   (`span_type_idx`, `hadith_arabic_number_idx`, `hadith_collection_idx`) and the 2 full-text indexes; creating two `Ayah {ayah_id:'0:0'}`
   fails with a constraint error; clean up the test nodes.
