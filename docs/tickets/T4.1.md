# T4.1 — Normalizer v2 (agy)

**Goal:** `text_norm` merges the Uthmani spelling variants found in T3.3, so Quran matching (4a) does not miss quotes.
Measured by Claude (2026-11-03) on the 77,383 words where corpus and Tanzil Uthmani align 1:1:
current normalizer → 319 words differ; v2 → **exactly 2** (`12:39:1`, `12:41:1`: «يَٰصَىٰحِبَىِ» vs «يَٰصَٰحِبَىِ», a real corpus spelling).

## Steps
1. `src/extract/normalize.py`: in `normalize_with_map`, after the existing rules, also **skip** (no output, no index
   entry) these characters: tatweel `ـ` U+0640, hamza `ء` U+0621, small waw `ۥ` U+06E5, small yeh `ۦ` U+06E6.
   (Hamza above/below U+0654/U+0655 are Mn and already skipped.) Keep `len(norm) == len(index)`.
2. Re-run `python scripts/tasks.py parse` and `python scripts/tasks.py load` so `Ayah.text_norm` and
   `TafsirSegment.text_norm` use v2 (MERGE + SET updates them; counts must not change).
3. Tests (`tests/test_normalize_v2.py`):
   - corpus `Word.text` vs Tanzil Uthmani token (ayat with equal word counts, from `data/interim`): exactly 2 differ, ids `12:39:1`, `12:41:1`;
   - `normalize_with_map("وَبِٱلْـَٔاخِرَةِ")[0] == normalize_with_map("وَبِٱلْءَاخِرَةِ")[0]`;
   - index strictly increasing, and `text[index[k]]` is never one of the skipped characters;
   - all existing tests pass unchanged — in particular the T2.3 locator offsets `(141, 657)`, `(658, 790)` and the G2 fixture.
4. `docs/schema.md` Conventions: update the `text_norm` definition. `docs/decisions.md`: record v2 and the measured 319 → 2.
