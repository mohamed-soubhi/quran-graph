# T4.2 — FOOTNOTE spans + span writer (agy)

**Goal:** every editor note `[[…]]` in Ibn Kathir is a `Span {type: 'FOOTNOTE'}` in Neo4j, and a reusable span writer
exists for 4a–4c. Deterministic (regex), no LLM.

## Facts (measured by Claude on the 1,911 segments)
31,203 `[[…]]` notes; `[[` and `]]` balanced in every segment; none nested; 110 span several lines (use DOTALL);
1,857 segments have at least one; longest 7,075 chars (`ibn-kathir:33:41-44:1`).

## Steps
1. `src/extract/footnotes.py`: `find_footnotes(text) -> list[tuple[int, int]]` with `\[\[.*?\]\]` (DOTALL); offsets in the
   original text, end exclusive, markers included.
2. `data/interim/spans/footnotes.jsonl`: one line per span: `span_id`, `segment_id`, `start`, `end`, `type`,
   `parent` (null for now — parents are set in 4c), `source` (`run:<yyyymmdd-hhmm>-footnotes`), `method: "regex"`,
   `confidence: 1.0`. Deterministic order (segment order, then start). `tasks.py spans` runs it.
3. `src/graph/spans.py`: `write_spans(rows)` — MERGE `Span` on `span_id`, set properties, MERGE
   `(TafsirSegment)-[:HAS_SPAN {source, method, confidence}]->(Span)`; if `parent` is set also `INSIDE` (with provenance).
   Idempotent, UNWIND batches.
4. Tests: exactly 31,203 footnote spans; every span text starts with `[[` and ends with `]]`; no two overlap; the G2
   footnote `ibn-kathir:2:255-255:1#5030-5057` exists; after writing, Neo4j has 31,203 `Span {type:'FOOTNOTE'}` and
   31,203 `HAS_SPAN`; a second write changes no count; `tests/test_load.py` provenance test still passes.
