# T1.2 — Download Ibn Kathir (Arabic)

**Goal:** all 6236 per-ayah JSON files of `ar-tafsir-ibn-kathir` in `data/raw/tafsir/ibn-kathir/<surah>/<ayah>.json`.

## Steps
1. Source: `https://raw.githubusercontent.com/spa5k/tafsir_api/main/tafsir/ar-tafsir-ibn-kathir/<surah>/<ayah>.json`
   (NOT jsDelivr — it rejects this repo). Ayah counts per surah come from the Tanzil file (T1.1).
2. Reuse `fetch()`; polite rate (max ~5 req/s), retry 3x with backoff, log failures.
3. Record the repo commit SHA used in `docs/sources.md`.
4. `tests/test_tafsir_raw.py`: 6236 files; each parses as JSON with keys `surah, ayah, text`;
   report (not fail) the count of empty texts and of texts identical to the previous ayah (grouped passages).

## Acceptance
- Tests pass; counts of empty/duplicate texts written into `docs/sources.md`.
- Commit `T1.2: ...`.
