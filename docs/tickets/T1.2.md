# T1.2 — Download Ibn Kathir (Arabic)

**Goal:** all 6236 per-ayah JSON files of `ar-tafsir-ibn-kathir` in `data/raw/tafsir/ibn-kathir/<surah>/<ayah>.json`,
byte-for-byte as served, from a pinned source version.

- Repo `spa5k/tafsir_api`, **pinned commit `eb82bb6294efe30ad5c135c03b1864afaa70e855`** (2026-09-30).
- URL: `https://raw.githubusercontent.com/spa5k/tafsir_api/eb82bb6294efe30ad5c135c03b1864afaa70e855/tafsir/ar-tafsir-ibn-kathir/<surah>/<ayah>.json`
  (2:255 → 200, 67,645 bytes; 114:6 → 200; 73:1 → 200, 38,785 bytes). Do NOT use jsDelivr (rejects this repo).
- Ayah counts per surah: read them from `data/raw/tanzil/quran-simple-clean.txt` (T1.1). Never hard-code.

## Steps
1. `src/ingest/tafsir_ibn_kathir.py` reusing `fetch()` from `src/ingest/download.py`.
2. **Checksums go to a per-source manifest**, not one line per file in `data/raw/CHECKSUMS.txt`:
   `data/raw/tafsir/ibn-kathir/MANIFEST.txt` (sha256, path, url, date per file; pass it as `checksums_path`).
   When all 6236 files exist, append ONE line for `MANIFEST.txt` itself to `data/raw/CHECKSUMS.txt`.
   Un-ignore `MANIFEST.txt` in `.gitignore` (like CHECKSUMS.txt) so it is committed; the JSON files are not.
3. Polite + resumable: at most 4 parallel downloads, timeout 30 s, retry 3× with backoff, skip files that already
   exist (re-running continues where it stopped). Log failures; the run ends with a count of missing files.
4. Run the download. It takes several minutes — run it as a normal (non-interactive) command and wait for it.
5. `tests/test_tafsir_raw.py` (skip if the folder is absent):
   - exactly 6236 files, one per (surah, ayah) from Tanzil; each parses as JSON with keys `surah, ayah, text`
     and the numbers match the file path;
   - every file's sha256 matches `MANIFEST.txt`.
6. `scripts/tafsir_stats.py` prints (and you copy into the report and `docs/sources.md`): total characters,
   number of empty texts, number of texts identical to the previous ayah's (grouped passages), number of distinct
   texts, and the 5 largest groups (first ayah, size). Read JSON as UTF-8.
