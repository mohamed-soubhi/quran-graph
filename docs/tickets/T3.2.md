# T3.2 — Quran parser → JSONL (agy)

**Goal:** `data/interim/quran/surahs.jsonl` (114 lines) and `ayat.jsonl` (6,236 lines), deterministic, following
`docs/schema.md` (L0 Surah, Ayah). No Neo4j here.

## Rules
- `Ayah.text` = Tanzil Uthmani, `text_simple` = Tanzil Simple-Clean, verbatim **except** the basmala prefix (schema Q1):
  for ayah 1 of every surah except 1 and 9, drop the first 4 words when they equal the 4 words of 1:1 compared with
  `src/extract/normalize.normalize_with_map` (diacritic-insensitive). 1:1 keeps the basmala (it is the ayah).
- `text_norm` = `normalize_with_map(text_simple)[0]`. `word_count` = words of `text` after the basmala rule.
- `Surah`: `surah_id, name, tname, type, revelation_order, ayah_count, has_basmala` (false only for 9) from T3.1 metadata.
- Output: UTF-8, one JSON object per line, `ensure_ascii=False`, keys sorted, lines ordered by surah then ayah.
  Running twice gives byte-identical files.
- `scripts/tasks.py parse` runs all Phase 3 parsers that exist.

## Tests (`tests/test_parse_quran.py`)
Exactly 114 / 6,236 lines; exactly **112** ayat whose `text` differs from the raw line (both variants); 1:1 and 9:1 equal raw;
normalized 112:1 = `قل هو الله احد`; sum of `word_count` = **77,881 − 448 = 77,433**; byte-identical rerun.
