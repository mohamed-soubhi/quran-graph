# T0.5 — Extraction smoke test

**Goal:** GLM returns schema-valid JSON for one tafsir paragraph, reliably.

## Steps
1. `src/extract/models.py`: pydantic `HadithSpan(start:int, end:int, cue:str, collection_hint:str|None, number_hint:str|None)`
   and `HadithSpanList(spans: list[HadithSpan])`.
2. `src/extract/glm_client.py`: call Ollama `/api/chat` with `format` = the JSON schema of `HadithSpanList`,
   `temperature: 0`, model from `GLM_MODEL` in `.env`.
3. Prompt = short English instruction + one few-shot example. Input = one hand-picked Ibn Kathir paragraph
   saved as `tests/fixtures/tafsir_sample.txt` (Claude supplies it; must contain at least one hadith).
4. Validate with pydantic; check `0 <= start < end <= len(text)`; log seconds per paragraph to `logs/`.
5. Script `scripts/extract_smoke.py` runs it 5 times.

## Acceptance
- Valid JSON in 5/5 runs; mean seconds per paragraph recorded in `docs/decisions.md`.
- Commit `T0.5: ...`.
