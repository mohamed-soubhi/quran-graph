# T3.4 — Ibn Kathir segments → JSONL (agy)

**Goal:** `data/interim/tafsir/ibn-kathir/segments.jsonl` — one line per passage (decision 2026-10-29 + schema Q2:
whole passage, stored once), with the ayat it covers.

## Rules
- A passage = a run of consecutive ayat **in one surah** with identical `text` in the raw files.
- `segment_id = "ibn-kathir:<surah>:<first>-<last>:1"`; fields `book_id, surah_id, first_ayah, last_ayah, n=1, text`
  (verbatim, never edited), `text_norm` (`normalize_with_map(text)[0]`), `char_count`, `covers` (list of ayah_ids).
- Also `mufassir.jsonl` / `book.jsonl` with the values in `docs/schema.md` (Ibn Kathir, d. 774 AH; `source spa5k@eb82bb6`).
- Deterministic, sorted output.

## Tests (`tests/test_parse_tafsir.py`)
Exactly **1,911** segments; `covers` total **6,236**, every ayah exactly once; `text` equals the raw text of every covered
ayah; sum of `char_count` = **13,401,179**; largest group = 74:11–30 (20 ayat); `ibn-kathir:2:255-255:1`,
`ibn-kathir:30:30-32:1`, `ibn-kathir:4:116-122:1` exist (G2 fixture IDs); byte-identical rerun.
