# T3.3 — Quranic Corpus parser → JSONL, Arabic script (agy)

**Goal:** `data/interim/corpus/words.jsonl`, `lemmas.jsonl`, `roots.jsonl` + link lists, in **Arabic script**
(decision 2026-10-31), Buckwalter kept only as `bw`.

## Steps
1. `src/ingest/buckwalter.py`: the extended Buckwalter table from https://corpus.quran.com/java/buckwalter.jsp
   (Claude's checked draft: `.scratch/bw_demo.py`, may be copied), `to_arabic()`, `to_buckwalter()`, `split_lemma()`
   (`EaAd2` → (`EaAd`, 2)). Unknown character → raise.
2. Parser reading the zip in place (`src/ingest/quranic_corpus.py`). One word = all segments of `(s:a:w)`.
   - Word: `word_id "s:a:w"`, `ayah_id`, `position`, `text` (Arabic, segments joined), `bw`, `pos` (POS of the first STEM segment).
   - Lemma: `lemma_id` = Arabic text + `#<sense>` when a sense exists; `text`, `sense`, `bw`.
   - Root: `root_id` = `text` = Arabic letters without spaces; `bw`.
   - Links (JSONL): word→lemma (`segment` number), word→root, lemma→root.
3. Deterministic, sorted output, like T3.2.
