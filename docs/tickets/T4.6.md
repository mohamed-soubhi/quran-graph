# T4.6 — 4c Poetry (OTHER) + nesting (INSIDE) + COMMENTARY + coverage (agy)

**Goal:** finish the span layer of Phase 4. Add poetry as `OTHER` spans, give every nested span its parent (`INSIDE`),
fill every gap between top-level spans with `COMMENTARY`, and prove that top-level spans cover 100 % of every segment with no overlap.
Everything is deterministic (no LLM). agy builds the JSONL files, the tests and a loader, and **stops**.
**Claude writes to the real Neo4j** after the user approves.

## Decisions (Aya & Mohamed, 2026-11-17)
- **D1. Every gap becomes COMMENTARY**, including gaps with no letters (a single space, `" .\n\n"`). Such a span gets `blank: true`;
  every other COMMENTARY span gets `blank: false`. Coverage is 100 % of all characters.
- **D2. Poetry is detected in T4.6** as `OTHER` spans (rule below). Poetry inside a `[[…]]` footnote is not a span (spans inside footnotes are not created in Phase 4, decisions.md).
- Not in scope: re-typing the ~11 reference-only HADITH spans from T4.5c («حكاه … عن», «كما في حديث»). They stay HADITH; G4 reviews them.

## Steps
1. **Poetry → `data/interim/spans/poetry.jsonl`** (new `src/extract/poetry.py`, pure functions).
   a. A line (maximal run of non-`\n` characters) is a **verse line** when, after removing `[[…]]` footnotes and Arabic diacritics (U+064B–U+0652, U+0670) and stripping spaces,
      it contains ` ... ` or ends with ` ...`, **and** is at most 100 characters long. (Longer lines with ` ... ` are prose with an ellipsis — measured: 41 lines over 300 chars, all prose.)
   b. Consecutive verse lines separated only by whitespace form **one poem**. Span start = start of the first line.
   c. Span end = end of the last line, then trim backwards: trailing whitespace, then a trailing `[[…]]` footnote and the whitespace before it (repeat while one ends the span).
      A footnote **inside** the poem stays inside and becomes a nested child.
   d. Skip a verse line that lies inside a FOOTNOTE span. A poem never starts or ends inside a footnote.
   e. Record: `type: "OTHER"`, `span_id: "<segment_id>#<start>-<end>"`, `method: "regex"`, `confidence: 1.0`, `source: "run:<yyyymmdd-HHMM>-poetry"`, `lines: <n>`.
   Report the exact counts (lines, poems, by line count); explain any difference from 618 / 353 over 5.
2. **Nesting → parents** (new `src/extract/structure.py`). Read FOOTNOTE, QURAN, HADITH and OTHER spans. For each span, `parent` = the **smallest** span that contains it
   (`p.start <= c.start and c.end <= p.end`, not the same span). Same offsets in two files: parent order HADITH > QURAN > OTHER > FOOTNOTE (report how many; Claude expects 0).
   **Any partial overlap is an error**: the build stops and prints the span ids. Write `data/interim/spans/parents.jsonl`: one `{"span_id", "parent", "type", "parent_type"}`
   per nested span, sorted. Do **not** edit `footnotes.jsonl`, `quran.jsonl`, `hadith.jsonl`.
3. **COMMENTARY → `data/interim/spans/commentary.jsonl`.** For each segment, top-level spans = spans with no parent, in order. Every gap `[pos, next.start)` and the tail `[pos, len(text))`
   becomes one COMMENTARY span: `type: "COMMENTARY"`, `method: "regex"`, `confidence: 1.0`, `source: "run:<…>-commentary"`, `blank` per D1 (`blank: true` when the gap has no letter, `str.isalpha()` on every char false).
   A segment with no typed span is one COMMENTARY span of its whole text. Offsets refer to the original text (no normalization needed here).
4. **Gate 4c** — `scripts/gate_4c.py` (no Neo4j), prints a table and exits 1 on failure:
   - per segment: top-level spans (FOOTNOTE, QURAN, HADITH, OTHER, COMMENTARY without parent) are sorted, start at 0, touch each other (`a.end == b.start`) and end at `len(text)`;
     sum of their lengths = **13,401,179**; 0 overlaps; 0 partial overlaps anywhere;
   - every nested span lies inside its parent; children of the same parent do not overlap;
   - **gold:** all 4 gold `OTHER` spans found with exact offsets; for the 29 gold spans with a `parent`, when both child and parent exist in our output with the same offsets,
     our parent is the same span (report: matched / both-present / total). Gold files are read-only.
5. **Loader** — `python scripts/tasks.py structure --write` writes OTHER and COMMENTARY spans with `HAS_SPAN`, and `INSIDE` edges for every row in `parents.jsonl`,
   all with `source`, `method`, `confidence` on the edges (reuse `write_spans`; add `blank` and `lines` to the stored optional properties). Idempotent (MERGE): a second run
   changes no counts. Removes old `COMMENTARY` and `OTHER` spans first (only those two types). Never deletes FOOTNOTE, QURAN or HADITH spans.
   `python scripts/tasks.py structure` without `--write` runs steps 1–4 only.
6. **Tests** (no network): verse rule (W09-style line with trailing footnote → trimmed; a 150-char prose line with ` ... ` → not a verse; two verse lines with `\n\n` → one poem;
   a verse inside a footnote → skipped); parent = smallest container (footnote in quote in hadith → parent is the quote); partial overlap → error;
   COMMENTARY fills gaps exactly, `blank` true for `" .\n\n"`; segment with no spans → one span; gate on a tiny fixture passes and fails on a 1-char hole.
   Neo4j tests may only create and delete spans whose `span_id` starts with `test:` — **never** `MATCH (s:Span {type: …}) DETACH DELETE` on real types in a test.
7. **Run** `python scripts/tasks.py structure` on the real data and put the gate table in the report. **Do not run `--write`.**
