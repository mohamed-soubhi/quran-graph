# T1.3 — Download hadith collections (Arabic)

**Goal:** the 10 diacritized Arabic editions from fawazahmed0/hadith-api in `data/raw/hadith/fawazahmed0/`,
byte-for-byte as served, from a pinned source version.

## Source (verified by Claude 2026-10-31)
- Repo `fawazahmed0/hadith-api` (Unlicense), branch `1`, **pinned commit `df57907be35291c91ad6a6691180e22ca9920784`** (2026-06-03).
- Base URL: `https://raw.githubusercontent.com/fawazahmed0/hadith-api/df57907be35291c91ad6a6691180e22ca9920784/`
  - `editions.json` (30,390 bytes) — list of collections.
  - `editions/ara-<collection>.json` — full collection, e.g. `ara-bukhari.json` 9,770,083 bytes, `ara-muslim.json` 8,685,140.
- Collections (10): abudawud, bukhari, dehlawi, ibnmajah, malik, muslim, nasai, nawawi, qudsi, tirmidhi.
- Use `ara-<collection>` (**with diacritics**, e.g. 249 marks in Bukhari #1). NOT `ara-<collection>1` (no diacritics).
  Read the collection list from `editions.json`; do not hard-code it.

## Steps
1. `src/ingest/hadith_fawazahmed0.py` reusing `fetch()` (timeout 60 s, retries 3).
2. Save `editions.json` and the 10 files to `data/raw/hadith/fawazahmed0/`.
3. Checksums in `data/raw/hadith/fawazahmed0/MANIFEST.txt` (like T1.2); when all 11 files exist, append ONE line
   for that MANIFEST to `data/raw/CHECKSUMS.txt`. The MANIFEST is committed (the `.gitignore` rule from T1.2 covers it).
4. `tests/test_hadith_raw.py` (skip if the folder is absent): each file parses as JSON; every hadith has
   `hadithnumber` and non-empty `text`; sha256 of every file matches MANIFEST.
5. `scripts/hadith_stats.py` prints per collection: hadith count, count with ≥1 grade, distinct grader names
   (from `grades[].name`), and the most common 5 grade values. Read as UTF-8. Do NOT change or interpret grades.
   Copy the table into the report and `docs/sources.md`.
