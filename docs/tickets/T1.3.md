# T1.3 — Download hadith collections (Arabic)

**Goal:** the 10 Arabic editions from fawazahmed0/hadith-api in `data/raw/hadith/fawazahmed0/`.

## Steps
1. Read `https://cdn.jsdelivr.net/gh/fawazahmed0/hadith-api@1/editions.json`; for each collection take the
   `ara-<collection>` edition (not `ara-<collection>1`, the no-diacritics copy) and download `editions/ara-<collection>.json`.
2. Record the version / commit used in `docs/sources.md`.
3. `tests/test_hadith_raw.py`: each file parses; every hadith has `hadithnumber` and non-empty `text`;
   print per-collection count and how many hadiths have at least one grade.
