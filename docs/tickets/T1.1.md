# T1.1 — Download framework + Quran text (Tanzil)

**Goal:** a reusable downloader that records checksums, and the Tanzil Quran text in two variants.

## Steps
1. `src/ingest/download.py`: `fetch(url, dest_path)` — skip if file exists (data/raw is read-only once written),
   stream to disk, append `sha256  relative_path  url  date` to `data/raw/CHECKSUMS.txt`.
2. Download Tanzil v1.1 `uthmani` and `simple-clean`, format "text with aya numbers" (`surah|ayah|text`),
   into `data/raw/tanzil/quran-uthmani.txt` and `data/raw/tanzil/quran-simple-clean.txt`. Keep the file verbatim
   (licence: no changes; the `#` copyright block at the end must stay). Verified URL (2026-10-31, HTTP 200, 6236 ayah lines):
   `https://tanzil.net/pub/download/index.php?quranType=<uthmani|simple-clean>&outType=txt-2&agree=true`
   Write the bytes exactly as received (binary mode) — no newline or encoding conversion.
3. `tests/test_tanzil_raw.py`: 114 distinct surahs, 6236 lines of ayat in each file (ignore `#` comment and blank lines),
   both files have the same (surah, ayah) keys, and each file's SHA-256 matches CHECKSUMS.txt. Skip if the files are absent.

## Acceptance
- Tests pass; CHECKSUMS.txt has both files; re-running downloads nothing.
- Commit `T1.1: ...`.
