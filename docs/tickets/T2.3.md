# T2.3 — Extraction contract `docs/extraction_schema.json` (Claude + agy)

**Goal:** the fixed JSON contract for GLM output in Phase 4b, following the decision of 2026-10-30:
GLM returns quoted **anchor phrases**, never integer offsets; code locates them.

## Draft (Claude writes, agy implements the code)
- JSON Schema (draft 2020-12): `{ "spans": [ { "start_anchor", "end_anchor", "cue", "collection_hint", "number_hint" } ] }`
  — anchors are 3–8 words copied exactly from the input; hints may be null.
- `src/extract/models.py`: pydantic models generated to match (`HadithSpanAnchor`), old offset model kept until Phase 4b.
- `src/extract/locate.py`: anchor → (start, end) in the ORIGINAL text via the NFC/diacritic-stripped offset map.
- Tests: the schema file validates the T0.5 fixture converted to anchors; the locator returns exactly the fixture
  offsets `[141, 657)` and `[658, 790)` for 2:255 para 0.

## Acceptance
Tests pass; schema and pydantic model agree (a test compares their field sets).
