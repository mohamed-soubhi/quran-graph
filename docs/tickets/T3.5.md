# T3.5 — Neo4j writers (MERGE, idempotent) (agy)

**Goal:** load the T3.2–T3.4 JSONL into Neo4j exactly as `docs/schema.md` L0 + L1, surah by surah:
Al-Fatiha → Al-Baqarah → all (plan Phase 3).

## Rules
- `src/graph/load.py`, `python scripts/tasks.py load [--surah N]` (no flag = all). Applies the schema first (T2.2).
- `UNWIND` batches (≤ 5,000 rows) with `MERGE` on the unique keys; properties set with `SET`.
- Every relationship gets `source` (`tanzil-1.1` / `quranic-corpus-0.4` / `spa5k@eb82bb6`), `method: 'dataset'`, `confidence: 1.0`.
- Relationships: HAS_AYAH, NEXT (ayah → ayah, also across surahs), HAS_WORD, HAS_LEMMA, HAS_ROOT, LEMMA_OF_ROOT,
  WROTE, HAS_SEGMENT, COVERS, NEXT (segment → segment, book order).
- A segment is loaded with `--surah N` when its surah is N. Log counts per label and per relationship type.
