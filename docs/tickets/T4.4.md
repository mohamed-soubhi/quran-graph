# T4.4 — 4a Quran spans + ayah links (agy, no LLM)

**Goal:** every ﴿…﴾ quote in Ibn Kathir is a `Span {type:'QURAN'}` in Neo4j, linked to the ayah(s) it quotes with
`EXPLAINS` (ayah covered by the segment) or `CITES` (any other ayah). Deterministic: regex + token matching, no LLM.
Gate 4a: **precision ≥ 98 %** on the gold set `data/gold/phase4.jsonl`.

## Facts (measured by Claude)
- 26,686 ﴿…﴾ quotes in the 1,911 segments; brackets balanced; **none inside a footnote**; footnotes do occur *inside*
  quotes (e.g. ﴿اللَّهُ لَا إِلَهَ إِلا هُوَ [[في أ: …]]﴾ in 2:255).
- Gold set: 83 QURAN spans — 79 bracketed, 4 unbracketed (surah names inside a hadith, one qira'a; 1–4 words each);
  98 links; 66 spans with an EXPLAINS link, 17 with CITES; 9 multi-ayah; 14 with a written reference; 5 one-word quotes.
- Ibn Kathir quotes in the **simple** spelling → match against `Ayah.text_simple` (`data/interim/quran/ayat.jsonl`),
  both sides normalized with Normalizer v2 (`src/extract/normalize.py`) and punctuation turned into spaces.
- Hamza seats still differ after v2: Ibn Kathir «أَئِنَّا» vs Tanzil simple «أإنا» (56:47).
- Written references look like «[الرُّومِ: ٢٥]», «[الصافات: ٢٢، ٢٣]», «[النساء: ٨٢-٨٣]» (Arabic-Indic digits, `-` `،` `,`),
  right after the closing ﴾ (spaces allowed); one has a stray digit in the name «[٠الْفُرْقَانِ: ٧٢]».
  Surah names: `data/interim/quran/surahs.jsonl` (`name`), compared after v2 normalization, without a leading «سورة».

## Steps
1. `src/extract/quran_spans.py`
   - `find_quotes(text) -> list[tuple[int,int]]`: `﴿[^﴾]*﴾`, offsets in the original text, end exclusive, brackets included (C3).
   - `parse_ref(text_after) -> dict | None`: the written reference within 60 chars after ﴾ → `{"ref_text", "ayat": [...]}`.
   - `match_quote(quote, covers) -> (ayah_ids, method, confidence)`: drop `[[…]]` inside the quote, normalize, tokenize;
     find the token sequence as a contiguous run in the Quran token stream (it may start or end mid-ayah and run over
     several ayat → every ayah touched). Order of preference:
     1. a written reference → its ayat (`method: regex`, `confidence: 1.0`); if the text does not match those ayat,
        keep the reference and log it;
     2. exact match inside the ayat the segment covers (`ngram`, 1.0);
     3. exact unique match in the whole Quran (`ngram`, 1.0); several matches → prefer the segment's surah, else the first
        in mushaf order (`ngram`, 0.5), logged;
     4. if 1–3 fail, retry with a looser key that deletes ا ئ ؤ from both sides (`ngram`, 0.9);
     5. a one-word quote only matches inside covered ayat; otherwise no link.
     No match → the span is still written, with no link, and logged (never guessed).
   - `rel` = `EXPLAINS` if the ayah is in the segment's `covers`, else `CITES`. `ref_text` goes on the edge.
2. `data/interim/spans/quran.jsonl`: one line per span, same fields as `footnotes.jsonl` (`parent: null` — parents are
   set in T4.6) plus `links: [{ayah_id, rel, ref_text?, method, confidence}]`. Deterministic order and output.
   `tasks.py spans` runs it after the footnotes.
3. `src/graph/spans.py`: add link writing — MERGE `(Span)-[:EXPLAINS|CITES {source, method, confidence, ref_text}]->(Ayah)`.
   Idempotent, UNWIND batches. `write_spans` and the link writer return counts of what was actually written
   (from the query summary or a count query), not input row counts.
4. `scripts/eval_4a.py`: compare predicted QURAN spans that lie inside the gold windows with the gold spans.
   A prediction is correct when its offsets **and** its set of (ayah_id, rel) are identical to a gold span.
   Print and write `logs/eval-4a-<yyyymmdd-hhmm>.json`: precision, recall (bracketed gold only, 79), link accuracy,
   and every disagreement with the window id and quote text. The 4 unbracketed gold quotes are **not** detected in
   T4.4 — report them as missed, outside the gate.
5. Tests (`tests/test_quran_spans.py`): exactly 26,686 QURAN spans; every span text starts with ﴿ and ends with ﴾;
   none overlaps a footnote except footnotes fully inside it; `parse_ref` on the three reference shapes above and the
   stray-digit one; 56:47 matches via the loose key; the 2:255 quote ﴿اللَّهُ لَا إِلَهَ إِلا هُوَ [[…]]﴾ links to 2:255
   (EXPLAINS); gate test: precision ≥ 0.98 on the gold set; after writing, Neo4j has 26,686 `Span {type:'QURAN'}`,
   every link edge has `source`/`method`/`confidence`, and a second write changes no count.
