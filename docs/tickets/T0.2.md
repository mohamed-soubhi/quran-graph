# T0.2 — Neo4j + GDS in Docker

**Goal:** Neo4j 5 with the Graph Data Science plugin, persistent across restarts.

## Steps
1. `docker-compose.yml`: service `neo4j`, image `neo4j:5`, `NEO4J_PLUGINS=["graph-data-science"]`,
   ports 7474/7687, named volume for `/data`, `NEO4J_AUTH=${NEO4J_USER}/${NEO4J_PASSWORD}` from `.env`.
2. Memory (machine has 32 GB): heap initial/max 4G, page cache 4G.
3. `tasks.py up` → `docker compose up -d`; `tasks.py down` → `docker compose down`.
4. Start Docker Desktop if needed, run `tasks.py up`, check `docker compose logs neo4j`.
5. Run `RETURN gds.version();` (via cypher-shell in the container).

## Acceptance
- `gds.version()` returns a version; record it in `docs/decisions.md`.
- A test node survives `docker compose restart`.
- Commit `T0.2: ...`.
