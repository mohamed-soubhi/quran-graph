# T4.3 — Gold set for Phase 4 (Claude drafts, Aya & Mohamed review)

**Goal:** ~50 human-reviewed tafsir windows with every span marked, to measure the 4a and 4b gates
(Quran precision ≥ 98 %; hadith precision ≥ 90 %, recall ≥ 80 %, IoU ≥ 0.9).

## Design
- Unit = a **window** of a segment (one or a few paragraphs, ~300–1,500 chars), not a whole passage (up to 72k chars).
  Record: `segment_id`, `window_start`, `window_end`, and every span fully inside the window with offsets in the
  **segment** text: type, parent (nesting, C1), ayah links (EXPLAINS/CITES, C4 `ref_text`), hadith hints.
- Sample: stratified by surah (Meccan/Medinan, short/long), plus windows chosen for hard cases (Quran inside hadith,
  footnote inside a quote, isnad of a missing collection, written references, unbracketed quotes). Fixed random seed.
- Claude drafts every window; a **review page** (HTML, each span type highlighted in its own colour, the ayah text shown
  for each link) lets Aya & Mohamed check and correct. Their corrections make it gold: `data/gold/phase4.jsonl`
  (`reviewed_by`, date).
- The T0.5 fixture (2:255 para 0) is one of the windows.

## Acceptance
50 windows reviewed and approved by Aya & Mohamed; file committed in `data/gold/`; a test checks offsets against the raw text.
