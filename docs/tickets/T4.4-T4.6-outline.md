# Phase 4 — outline of T4.4–T4.6 (detailed after the gold set exists)

## T4.4 — 4a Quran spans (agy, no LLM)
- Candidates: the 26,686 ﴿…﴾ quotes (bracket boundaries given by the edition) outside footnotes; plus unbracketed quotes
  by n-gram (minimum length set from the gold set).
- Identify the ayah(s): first the written reference «[سورة: آية]» after the quote (C4, surah names from Tanzil metadata);
  else longest n-gram match against **`text_simple`** normalized with v2 — Ibn Kathir quotes in simple spelling
  («الْعَالَمِينَ», not Uthmani «ٱلْعَٰلَمِينَ»; after normalization Uthmani and Simple still differ in 3,777 ayat).
  Multi-ayah quotes → one edge per ayah.
- EXPLAINS if the ayah is covered by the segment, else CITES. Gate 4a: precision ≥ 98 % on the gold set.

## T4.5 — 4b Hadith spans (agy + GLM)
- Regex cues on v2-normalized text (حدثنا، رواه، أخرجه، قال رسول الله ﷺ …) → short windows → GLM anchors
  (`docs/extraction_schema.json`) → locator. Anchor matching ignores footnote characters (G2 finding, 4:116).
- Stored without CITES (linking is Phase 5). Gate 4b: precision ≥ 90 %, recall ≥ 80 %, IoU ≥ 0.9 over ≥ 3 runs.

## T4.6 — 4c Nesting + COMMENTARY + coverage (agy)
- Set `INSIDE` parents (footnote in quote, quote in hadith); fill gaps between top-level spans with COMMENTARY.
- Gate 4c: top-level spans cover 100 % of every segment, no overlap.
