﴿وَيْلٌ يَوْمَئِذٍ لِلْمُكَذِّبِينَ﴾ [الطُّورِ: ١١]. The reference is right (52:11 «فَوَيْلٌ يَوْمَئِذٍ لِلْمُكَذِّبِينَ»), but the
R1 reference check in `src/extract/quran_spans.py` did not find the words in 52:11 because of the «ف», and moved the link
to 77:15 (span `ibn-kathir:14:47-48:1#367-403`).

   R3 edge-token logic; exact, loose and skeleton keys as now.
2. Regenerate `data/interim/spans/quran.jsonl`, rewrite to Neo4j (idempotent, stale edges removed), regenerate

3. Tests: the span above links to **52:11** with `method: regex`, `confidence: 1.0`, `ref_text` «[الطُّورِ: ١١]»;
   the redirected-reference count goes from 40 to **39** (if another case changes, list it in the report);
