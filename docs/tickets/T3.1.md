# T3.1 — Download Tanzil Quran metadata (agy)

**Goal:** surah names (Arabic), ayah counts, Meccan/Medinan and revelation order are in `data/raw/`, checksummed and tested.
Needed for `Surah` nodes (Phase 3) and for surah-name → number lookup of references like «[الرُّومِ:٢٥]» (schema change C4, Phase 4a).

## Steps
1. With `src/ingest/download.py`, download `https://tanzil.net/res/text/metadata/quran-data.xml` to
   `data/raw/tanzil/quran-data.xml` (verbatim; 77,234 bytes when checked by Claude on 2026-11-03) and append its line to
   `data/raw/CHECKSUMS.txt` (URL, date).
2. `src/ingest/tanzil_metadata.py`: `read_suras(path) -> list[dict]` with `index, ayas, start, name, tname, ename, type, order, rukus`
   (ints as int). Parse with `xml.etree.ElementTree`; read the file as UTF-8.
3. `tests/test_tanzil_metadata.py` (skip if absent): sha256 matches CHECKSUMS; exactly 114 suras, index 1..114;
   sum of `ayas` = 6,236 and each surah's `ayas` equals its ayah count in `data/raw/tanzil/quran-uthmani.txt`;
   `start` of surah n+1 = start + ayas of surah n; `name` of 1 = «الفاتحة», of 2 = «البقرة», of 30 = «الروم»;
   86 Meccan + 28 Medinan (check this exact split; if it differs, report it under Deviations — do not change the test to match).
4. `docs/sources.md`: add the metadata file (licence attribute in the file: `cc-by`, Tanzil.info). `docs/references.md`: the URL.
