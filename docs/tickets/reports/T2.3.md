## What Changed

1. **`requirements.txt`**:
   - Pinned `jsonschema==4.26.0`.

2. **`docs/references.md`**:
   - Added PyPI reference for `jsonschema==4.26.0`.

3. **`src/extract/normalize.py`**:
   - Implemented `normalize_with_map(text: str) -> tuple[str, list[int]]`.
   - Iterates through original characters, skipping `unicodedata.category(c) == "Mn"`.
   - Maps `أ`, `إ`, `آ`, `ٱ` to `ا`, `ى` to `ي`, `ة` to `ه`.
   - Returns normalized string and 1:1 index array of original character offsets.

4. **`src/extract/models.py`**:
   - Defined `CollectionHint` type alias with `Literal["bukhari", "muslim", "abudawud", "tirmidhi", "nasai", "ibnmajah", "malik", "ahmad", "darimi", "other"]`.
   - Added `HadithSpanAnchor` matching schema item properties (`start_anchor`, `end_anchor`, `cue`, `collection_hint`, `number_hint`).
   - Added `HadithSpanAnchorList` container with `spans` list.
   - Retained legacy `HadithSpan` and `HadithSpanList`.

5. **`src/extract/locate.py`**:
   - Implemented `locate(text: str, anchor: HadithSpanAnchor, window_start: int = 0) -> tuple[int, int] | None`.
   - Normalizes text and anchors; searches for start anchor at or after `window_start` (mapped to normalized space via `bisect.bisect_left`).
   - Searches for end anchor at or after start position.
   - Computes base offsets: `start = index[s]`, `end = index[e + len(norm_end) - 1] + 1`.
   - Extends `end` first over trailing `Mn` diacritics of the final letter, then over closing punctuation marks `{"\"", "”", "»", ")", "]", "﴾"}`.
   - Rejects spans where `start` falls inside `[[...]]` editor footnotes by returning `None` and logging a warning.

6. **`src/extract/glm_client.py`**:
   - Added `ollama_format(schema: dict) -> dict` helper function that recursively strips `$id`, `$schema`, and keys starting with `x-`.

7. **`tests/test_extraction_contract.py`**:
   - `test_schema_is_valid_json_schema`: Validates `docs/extraction_schema.json` using `jsonschema.validators.validator_for(schema).check_schema(schema)`.
   - `test_model_matches_schema_item`: Verifies `HadithSpanAnchor` field set and `required` list match schema `spans.items` exactly.
   - `test_fixture_example_validates_against_schema`: Verifies sample Ahmad & Muslim anchor data against JSON schema and Pydantic model.
   - `test_locate_exact_fixture_offsets`: Asserts `locate()` produces exactly `(141, 657)` and `(658, 790)` on `tests/fixtures/tafsir_sample.txt`.
   - `test_locate_not_found_and_footnote`: Asserts `locate()` returns `None` for missing anchors and anchors occurring inside `[[...]]` footnotes (e.g. `وصحيح مسلم برقم`).
   - `test_normalize_with_map_properties`: Validates `len(norm) == len(index)`, strictly increasing indices, diacritic stripping, and letter normalization.
   - `test_ollama_format_strips_metadata_and_extensions`: Validates stripping of `$id`, `$schema`, and `x-*` keys.

8. **`docs/tickets/TRACKER.md`**:
   - Updated ticket row `T2.3` status to `review`.
