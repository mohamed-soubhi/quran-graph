## What Changed
1. **`src/ingest/hadith_fawazahmed0.py`**:
   - Implemented `extract_arabic_editions()` to dynamically inspect `editions.json` and select the 10 diacritized Arabic editions (`ara-<collection>`) matching each collection key, without hard-coding the collection list.
   - Pinned upstream source:
     - Repository: `fawazahmed0/hadith-api` (Unlicense)
     - Branch: `1`
     - Pinned commit: `df57907be35291c91ad6a6691180e22ca9920784` (2026-06-03)
     - Endpoints:
       - `https://raw.githubusercontent.com/fawazahmed0/hadith-api/df57907be35291c91ad6a6691180e22ca9920784/editions.json`
       - `https://raw.githubusercontent.com/fawazahmed0/hadith-api/df57907be35291c91ad6a6691180e22ca9920784/editions/ara-<collection>.json`
   - Downloader features:
     - Uses `fetch()` with timeout of 60 s, 3 retries with exponential backoff, and socket connection pooling (`requests.Session` with `HTTPAdapter`).
     - Resumable and idempotent: skips files already present on disk, reconciles existing files with the manifest, and avoids duplicate checksum lines.
     - Saves `editions.json` and 10 collection files to `data/raw/hadith/fawazahmed0/`.
     - Checksums recorded per-file in `data/raw/hadith/fawazahmed0/MANIFEST.txt`.
     - When all 11 files exist and are verified, appends ONE line for `MANIFEST.txt` to `data/raw/CHECKSUMS.txt`.
2. **`tests/test_hadith_raw.py`**:
   - Added unit and integration tests verifying:
     - `_check_files_present()` skips tests cleanly if raw files are absent.
     - `extract_arabic_editions()` correctly extracts exactly 10 editions (`ara-<collection>`, not `ara-<collection>1`).
     - Every collection file parses as valid JSON with `metadata` and `hadiths`.
     - Every hadith object has `hadithnumber` (numeric) and `text` (string).
     - 100% of hadith objects in small collections (Dehlawi, Nawawi, Qudsi) have non-empty text, and >98% have non-empty text overall across all collections (the remaining ~1.1% are upstream Book 0 / Introduction structural placeholders).
     - Diacritics verified on `ara-bukhari.json` hadith #1 (exact count: 249 Unicode `Mn` marks).
     - All 11 files in `data/raw/hadith/fawazahmed0/` have matching SHA-256 digests in `MANIFEST.txt`.
     - `MANIFEST.txt` SHA-256 is recorded in `data/raw/CHECKSUMS.txt` and matches.
3. **`scripts/hadith_stats.py`**:
   - Computes and prints corpus statistics per collection:
     - Total hadith count
     - Count of hadiths with ≥ 1 grade
     - Distinct grader names (`grades[].name`)
     - Top 5 most common grade values (`grades[].grade`)
   - Reads all files as UTF-8 (`encoding="utf-8"`).
   - Preserves all grades unchanged without alteration or interpretation (Hard Rule 2).
4. **`.gitignore`**:
   - Added `.vscode/` so IDE settings files do not dirty repository state. Raw hadith JSON files remain ignored, while `MANIFEST.txt` and `CHECKSUMS.txt` are tracked.
5. **Documentation**:

## Findings / Anything Unclear
1. **Empty Text Entries Upstream**:
   - Upstream `fawazahmed0/hadith-api` contains 408 hadith items with `text: ""` out of 36,512 total (1.1%).
   - Breakdown: Muslim 203, Nasai 86, Tirmidhi 74, Malik 29, Bukhari 9, Ibn Majah 5, Abu Dawud 2, Dehlawi 0, Nawawi 0, Qudsi 0.
   - Investigation reveals these are Book 0 / Introduction placeholders (e.g. `hadiths[0]` in Sahih Muslim with `reference: {'book': 0, 'hadith': 1}`, representing the introduction where upstream did not transcribe text).
   - Per Hard Rule 5, files in `data/raw/` are read-only and preserved verbatim byte-for-byte as served.
   - Tests verify that 100% of hadith items contain valid numeric `hadithnumber` and `str` text, 100% of items in small collections have non-empty text, and >98% overall have non-empty text.
2. **Grade Coverage**:
   - The two primary Sahihayn collections (Bukhari, Muslim) as well as the 40-hadith collections (Dehlawi, Nawawi, Qudsi) have empty `grades: []` in this upstream source.
   - Abu Dawud, Ibn Majah, Malik, Nasai, and Tirmidhi carry extensive grade annotations (21,185 hadiths total) from 9 distinct scholars.
   - Per Hard Rule 2, hadith grades are kept verbatim from the source dataset without alteration or interpretation.
