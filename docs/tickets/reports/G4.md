### What each step checks
1. **Set the console to UTF-8** so cmd can print Arabic. It changes nothing in the project.
2. **Gate 4a, the Quran quotes.** It compares the QURAN spans inside the 50 gold windows with the 79 bracketed quotes Mohamed reviewed. A quote counts as correct only when both its offsets and its ayah links are identical.
   - 100 % means none of the 79 is wrong.
   - The 4 "unbracketed missed" are quotes without ﴿ ﴾. They are outside 4a by decision.
3. **The G4 gate script.** It only reads Neo4j and the files; it never writes. Its six steps:
   - **Step 1:** the Quran text and tafsir (L0/L1) still have exactly the G3 counts, so Phase 4 changed nothing there.
   - **Step 2:** every span type in Neo4j has exactly as many spans as its JSONL file, so nothing was lost or doubled while loading.
   - **Step 3:** the coverage queries 11.1–11.3 run inside Neo4j. All 0 means every character of every passage belongs to exactly one top-level span, and every nested span sits inside one parent.
   - **Step 4:** no relationship in the graph is missing its `source`, `method` or `confidence`.
   - **Step 5:** it scores the hadith spans stored in the graph against the 24 gold hadith, using the same rules and targets as Gate 4b. It also prints the one false positive and the one missed hadith.
   - **Step 6:** Gate 4c runs again on the files.
4. **The exit code.** `0` means every step passed. Any failure gives `1`, so a script or a person can tell without reading the output.
5. **Gate 4b, already run** (the 3 live GLM runs, 75 calls). This step only prints the saved log, so you can see the numbers without spending quota. Each run sends the 50 gold windows to GLM again and compares the answers with the gold spans:
   - **precision:** how many found spans are real.
   - **recall:** how many gold hadith were found.
   - **IoU:** how exactly the start and end match.
   - Three passing runs show the result does not depend on luck.
6. **Optional: see one live run yourself.** The numbers can differ a little, because GLM is not fully deterministic, but they must stay above the targets.
7. **The full test suite**, so nothing older broke. The 3 skipped are the old G2 fixture tests; they skip because real data is in Neo4j.
