## What Changed
1. **`src/extract/footnotes.py`**:
   - Implemented `find_footnotes(text: str) -> list[tuple[int, int]]` using `re.compile(r"\[\[.*?\]\]", re.DOTALL)`.
   - Implemented `extract_footnotes(segments_path, output_path, source)` generating deterministic JSONL at `data/interim/spans/footnotes.jsonl`.
   - Added CLI entry point with optional arguments (`--segments`, `--output`, `--source`).

2. **`src/graph/spans.py`**:
   - Reusable span writer for Phase 4 (4a–4c).
   - Implemented `write_spans(rows, driver, batch_size)`:
     - MERGE `Span` on `span_id` setting `segment_id`, `start`, `end`, `type`, and optional hints (`cue`, `collection_hint`, `number_hint`).
     - MATCH `TafsirSegment` and `Span`, MERGE `(TafsirSegment)-[:HAS_SPAN]->(Span)` setting provenance (`source`, `method`, `confidence`).
     - When `parent` is set: MATCH child and parent `Span`, MERGE `(Span)-[:INSIDE]->(Span)` setting provenance (`source`, `method`, `confidence`).
   - Implemented `load_spans_file(path, driver, batch_size)` and CLI entry point.

3. **`scripts/tasks.py`**:
   - Added target `spans` to `TARGETS` (`run_spans`):
     - `python scripts/tasks.py spans` extracts footnotes into `data/interim/spans/footnotes.jsonl`.
     - `python scripts/tasks.py spans --write` extracts and writes spans into Neo4j via `src/graph/spans.py`.

4. **`tests/test_footnotes.py`**:
   - `test_find_footnotes_unit`: Unit test for single-line, multiline, empty, and note-free text.
   - `test_extracted_footnotes_counts_and_properties`: Validates 31,203 spans, bracket markers, no overlaps, G2 footnote, 110 multiline, 1,857 segments, and longest note 7,075 chars.
   - `test_byte_identical_rerun`: Verifies byte-identical rerun output for `footnotes.jsonl`.
   - `test_neo4j_write_spans_and_idempotence`: Verifies 31,203 `Span` nodes and 31,203 `HAS_SPAN` edges in Neo4j, G2 node and edge properties, and strict count equality after a second write.
   - `test_write_spans_with_inside_parent`: Verifies reusable nesting via `INSIDE` relationship with provenance.
