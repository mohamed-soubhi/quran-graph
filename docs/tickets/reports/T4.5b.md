## What Changed

1. **GLM Prompt & Parser Resilience (`src/extract/glm_client.py`)**:
   - Added constant `PROMPT_VERSION = "1.2"`.
   - Updated `ANCHOR_SYSTEM_PROMPT`: explicit single JSON object constraint, no explanation, no markdown fences, escaped quotes `\"` explicitly enforced and demonstrated in few-shot example outputs, `collection_hint` strictly constrained to the 10 canonical values with fallback to `"other"`.
   - Pure function `parse_anchor_response(raw: str) -> ParsedAnchors` (no network):
     - Decodes the first JSON object using `raw_decode`, ignoring surrounding markdown fences and trailing commentary.
     - Validates **span by span**: unknown `collection_hint` becomes `"other"` (span kept, counter incremented); invalid/missing anchors dropped and counted; unknown `kind` (not `"marfu"` or `"athar"`) drops the span.
     - Raises `GlmResponseError` if no JSON object could be decoded.
   - Updated `extract_hadith_anchors`: executes up to 3 retry attempts, logging each attempt. If all attempts fail, raises `GlmExtractionError`. An empty list returned strictly denotes that GLM returned `"spans": []` (no silent failures).

2. **Bounded Span Locator (`src/extract/hadith_spans.py`)**:
   - `locate_and_check_anchors`: accepts `window_end` and `rejected` collector list.
   - Enforces `window_start <= start < end <= window_end`. Any anchor that matches beyond the given window boundaries is rejected with `reason: "outside_window"` (resolving Fact 13).
   - Every rejection records an explicit reason: `"not_found"`, `"outside_window"`, `"inside_footnote"`, `"inside_quote"`, `"too_long"`, `"duplicate"`.
   - Updated `extract_hadith_spans_for_segment`: catches `GlmExtractionError`, logs and prints failed windows.

3. **Evaluation and Benchmark Scripts (`scripts/eval_4b.py`, `scripts/hadith_throughput.py`)**:
   - `scripts/eval_4b.py`: catches `GlmExtractionError`, records `failed_windows`. The evaluation run strictly fails if any window fails (`len(all_failed_windows) == 0`).
   - `scripts/hadith_throughput.py`: catches `GlmExtractionError`, records failed windows, passes `window_end` to locator.

4. **Neo4j Span Writer (`src/graph/spans.py` & `scripts/tasks.py`)**:
   - Updated `merge_span_query` to set `s.kind = row.kind` on `Span` nodes.
   - Added `delete_spans_by_type(span_type='HADITH', driver=...)`.
   - Added `write_hadith_spans(path, driver=...)`: purges existing `Span {type: 'HADITH'}` nodes first, then writes new records idempotently with `kind` preserved.
   - Added target `hadith-spans` to `scripts/tasks.py` (`python scripts/tasks.py hadith-spans --write`).

5. **Whole-Book Runner and Build Pipeline (`scripts/run_hadith_book.py`)**:
   - Fixed deterministic window order across all 1,911 segments: `find_cue_paragraphs` + `split_long_paragraph` yielding 12,770 windows with key `<segment_id>#<start>-<end>`.
   - Batched execution (batches of `max(concurrency * 2, 8)`) keeping memory usage flat (measured at 42.8 MB Working Set).
   - Real-time persistence: appends one JSON line per window to `data/interim/spans/hadith-raw.jsonl` with immediate flush (`f.flush()`).
   - Robust resume: skips windows with status `ok`; retries windows with status `failed`; cleanly ignores truncated or half-written trailing lines.
   - Automatic stop rule: stops automatically with exit code 2 if > 20% of the last 200 windows fail.
   - Progress reporting every 100 windows: done in run / total book, failed count, seconds per call, estimated hours left.
   - Pure build step `--build`:
     - Reads latest `ok` record per key from raw JSONL without making any GLM calls.
     - Parses, locates within window bounds, and checks all spans.
     - Resolves overlapping spans: identical offsets merged; partial overlaps keep the longer span and reject the shorter one with `reason: "overlap"`.
     - Assigns `confidence`: `0.9` for exact matches, `0.8` for shorter-anchor fallbacks.
     - Outputs `data/interim/spans/hadith.jsonl` and `data/interim/spans/hadith-rejected.jsonl`.
     - Prints comprehensive totals: windows ok, failed, no span; spans by kind; rejections by reason; fallback counts; span length min/median/max.

6. **Unit Tests (`tests/test_hadith_spans.py`)**:
   - 8 new comprehensive unit tests (no network):
     1. Three logged failures as raw strings: trailing commentary after JSON; unknown collection `tabari` mapped to `other`; unescaped quotes raising `GlmResponseError` and retry with escaped quotes succeeding.
     2. Mocked client failing 3 times raises `GlmExtractionError` (never empty list).
     3. Bounded locator rejecting spans ending past `window_end` with `reason: "outside_window"`.
     4. Resume logic skipping `ok` keys and retrying `failed` keys.
     5. Truncated/corrupted trailing lines in raw JSONL safely ignored.
     6. Stopping rule triggering at > 20% failures (41/200 triggers, 40/200 does not, <200 does not).
     7. Overlap resolution merging identical offsets and rejecting shorter overlapping spans with `reason: "overlap"`.
     8. Neo4j span writer persisting `s.kind` on `HADITH` spans and clean deletion.
   - Total test suite expanded to 108 items (105 passed, 3 skipped).
