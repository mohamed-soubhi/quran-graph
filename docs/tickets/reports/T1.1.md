# T1.1 Report — Download framework + Quran text (Tanzil)

**Date:** 2026-10-31  
**Status:** review  

## What Changed
1. **`src/ingest/download.py`**:
   - Implemented `fetch(url, dest_path, timeout=60.0, chunk_size=65536, checksums_path=CHECKSUMS_FILE)`:
     - Checks if `dest_path` exists; skips download and log info if already present (enforcing read-only `data/raw`).
     - Streams bytes to a temporary `.tmp` file in binary mode (`"wb"`) with no encoding or newline conversion to guarantee verbatim storage.
     - Hashes content using SHA-256 during streaming.
     - Atomically replaces destination path with downloaded file upon completion.
     - Handles errors by cleaning up partial temporary files before re-raising.
     - Appends `sha256  relative_path  url  date` to `data/raw/CHECKSUMS.txt`.
   - Implemented helper functions `calculate_sha256()`, `append_checksum()`, `read_checksums()`, and `download_tanzil()`.
2. **`data/raw/CHECKSUMS.txt`**:
   - Created checksum manifest tracking SHA-256 digests, relative repo paths, download URLs, and access date.
   - Recorded checksums for both Tanzil v1.1 text files:
     - `data/raw/tanzil/quran-uthmani.txt`: `bf4f57b968d03f4131c070b1e285da9be0e0a108a21c910e872801ca273312c8`
     - `data/raw/tanzil/quran-simple-clean.txt`: `228df2a717671aeb9d2ff573002bd28d6b3f973f4bc7153554e3a81663d67610`
3. **`.gitignore`**:
   - Un-ignored `!data/raw/CHECKSUMS.txt` so the checksum manifest is tracked in git while raw data files (`data/raw/*`) remain git-ignored.
4. **`tests/test_download.py`**:
   - Added unit tests for `calculate_sha256`, `append_checksum`, `read_checksums`, and `fetch` (skipping existing files and atomic download recording).
5. **`tests/test_tanzil_raw.py`**:
   - Added validation tests:
     - Skip if raw files are absent.
     - Verify SHA-256 matches `CHECKSUMS.txt` for both files.
     - Verify exactly 6,236 ayah lines and 114 distinct continuous surahs (1..114) in both files (skipping `#` comments and blank lines).
     - Verify identical `(surah, ayah)` keys in matching order between `uthmani` and `simple-clean`.
6. **Documentation**:
   - Updated `docs/decisions.md` with verified Tanzil v1.1 counts, formats, and SHA-256 checksums.
   - Updated `docs/tickets/TRACKER.md` setting `T1.1` status to `review`.
