## What Changed

1. **`src/graph/schema.cypher`**:
   - One Cypher statement per line with `IF NOT EXISTS` for all constraints and indexes.
   - 13 unique constraints (`<label>_<property>_unique`):
     - `surah_surah_id_unique` on `(Surah).surah_id`
     - `ayah_ayah_id_unique` on `(Ayah).ayah_id`
     - `word_word_id_unique` on `(Word).word_id`
     - `root_root_id_unique` on `(Root).root_id`
     - `lemma_lemma_id_unique` on `(Lemma).lemma_id`
     - `mufassir_mufassir_id_unique` on `(Mufassir).mufassir_id`
     - `tafsir_book_book_id_unique` on `(TafsirBook).book_id`
     - `tafsir_segment_segment_id_unique` on `(TafsirSegment).segment_id`
     - `span_span_id_unique` on `(Span).span_id`
     - `hadith_book_collection_unique` on `(HadithBook).collection`
     - `hadith_hadith_id_unique` on `(Hadith).hadith_id`
     - `grader_name_unique` on `(Grader).name`
     - `narrator_narrator_id_unique` on `(Narrator).narrator_id`
   - 3 range indexes (`<label>_<property>_idx`):
     - `span_type_idx` on `(Span).type`
     - `hadith_arabic_number_idx` on `(Hadith).arabic_number`
     - `hadith_collection_idx` on `(Hadith).collection`
   - 2 full-text indexes:
     - `ayah_text_norm_ft` on `(Ayah).text_norm`
     - `segment_text_norm_ft` on `(TafsirSegment).text_norm`

2. **`src/graph/apply_schema.py`**:
   - `apply_schema(driver=None, schema_path=None)`: parses `schema.cypher`, extracts constraint/index names, executes each statement with `get_driver()`, and logs each name via `src.log.get_logger("apply_schema")`.
   - `main()`: CLI entry point with status report and error exit code.

3. **`scripts/tasks.py`**:
   - Added `run_schema()` function and `"schema": run_schema` target to `TARGETS`.
   - `python scripts/tasks.py schema` executes `src/graph/apply_schema.py`.

4. **`tests/test_graph_schema.py`**:
   - `driver` fixture skips when Neo4j is unreachable unless `SMOKE_STRICT=1`.
   - `test_schema_idempotency`: verifies running `apply_schema(driver)` twice executes without error and returns all 18 names.
   - `test_schema_constraints`: verifies `SHOW CONSTRAINTS` contains exactly the 13 unique constraints matching the schema label/property pairs.
   - `test_schema_indexes`: verifies `SHOW INDEXES` contains the 3 range indexes (`span_type_idx`, `hadith_arabic_number_idx`, `hadith_collection_idx`) and the 2 full-text indexes (`ayah_text_norm_ft`, `segment_text_norm_ft`) with correct types and properties.
   - `test_ayah_unique_constraint`: creates an `Ayah` node, verifies that attempting to create a second `Ayah` node with identical `ayah_id` raises `neo4j.exceptions.ConstraintError`, and cleans up in `finally`.

5. **`docs/tickets/TRACKER.md`**:
   - Updated `T2.2` row to status `review`.
