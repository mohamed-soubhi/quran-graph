# T1.2 Report — Download Ibn Kathir (Arabic)

**Date:** 2026-10-31  
**Status:** review  

## What Changed
1. **`src/ingest/download.py`**:
   - Added `_checksum_lock` (`threading.Lock`) to `append_checksum()` to guarantee thread-safe writes when multiple workers record digests concurrently.
   - Enhanced `fetch()`:
     - Added retry logic with exponential backoff (`retries: int = 0`, `backoff_factor: float = 0.5`).
     - Added support for passing an existing connection-pooled `requests.Session` (`session`).
     - Process- and thread-unique temporary files (`.tmp.<pid>.<tid>`) to prevent collision during concurrent downloads.
2. **`src/ingest/tafsir_ibn_kathir.py`**:
   - Implemented dynamic Tanzil reference loader `load_surah_ayah_pairs()` from `data/raw/tanzil/quran-simple-clean.txt`, verifying 114 surahs and 6,236 ayat (no hard-coding).
   - Configured pinned upstream source:
     - Repository: `spa5k/tafsir_api`
     - Pinned commit: `eb82bb6294efe30ad5c135c03b1864afaa70e855` (2026-09-30)
     - URL endpoint: `https://raw.githubusercontent.com/spa5k/tafsir_api/eb82bb6294efe30ad5c135c03b1864afaa70e855/tafsir/ar-tafsir-ibn-kathir/{surah}/{ayah}.json`
   - Downloader features:
     - Concurrency: 4 parallel worker threads (`ThreadPoolExecutor`) with keep-alive socket connection pooling (`HTTPAdapter(pool_connections=4, pool_maxsize=4)`).
     - Network safety: timeout of 30 s on every call, retry 3× with backoff.
     - Resumable: skips existing non-empty files on disk and reconciles disk files with `MANIFEST.txt`.
     - Manifest management: per-file SHA-256 records written to `data/raw/tafsir/ibn-kathir/MANIFEST.txt`.
     - Upon successful download and verification of all 6,236 files, appends one line for `MANIFEST.txt` itself to `data/raw/CHECKSUMS.txt`.
3. **`.gitignore`**:
   - Configured `.gitignore` to keep raw JSON files ignored while tracking `data/raw/CHECKSUMS.txt` and `!data/raw/**/MANIFEST.txt`.
4. **`tests/test_download.py`**:
   - Added unit tests for `fetch()` with transient failure retries and retry exhaustion.
5. **`tests/test_tafsir_raw.py`**:
   - Added tests verifying:
     - Tanzil loader returns 6,236 continuous ayat pairs across 114 surahs.
     - Exactly 6,236 per-ayah JSON files exist in `data/raw/tafsir/ibn-kathir/<surah>/<ayah>.json`.
     - Every file parses as valid JSON with keys `surah`, `ayah`, and `text`, with numbers matching the file path.
     - Every file's SHA-256 digest matches `MANIFEST.txt`.
     - `MANIFEST.txt` is recorded in `data/raw/CHECKSUMS.txt` and its digest matches.
6. **`scripts/tafsir_stats.py`**:
   - Analyzed all 6,236 downloaded files and computed corpus stats:
     - Total ayat: 6,236

     - Empty texts: 0
