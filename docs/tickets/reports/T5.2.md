## What changed
1. **Footnote reference parser and owner resolution (`src/extract/hadith_refs.py`):**
   - Implemented `Ref` dataclass with `collection`, `number`, and `ref_text`.
   - `parse_refs(footnote_text)`: pure function trying collection patterns in priority order:
     `nasai_kubra` > `bukhari` > `muslim` > `abudawud` > `tirmidhi` > `ibnmajah` > `nasai`.
     Handles Arabic-Indic digits conversion, multiple numbers in one bracket `N(، N)*`, and chained `وبرقم (...)` groups. Negative lookbehind ensures words like «للبخاري» are never matched.
   - `owner(footnote, parent_map, hadith_by_seg, segments)`: implements inside-wins (following parent chain for footnotes nested inside QURAN/HADITH) and after-hadith takhrij matching (`[\s.,،:؛"»)]*`).
   - `resolve(ref, hadith_ids, muslim_arabic)`: implements Decision D1 for Muslim (`arabic_number` = N or starts with N.), `not_in_sources` for `nasai_kubra`, and `<collection>:<N>` for others.
   - `compute_4gram_sim(span_clean_norm, hadith_clean_norm)`: computes 4-gram containment similarity: $|A \cap B| / \min(|A|, |B|)$.
   - `build_footnote_links(...)`: generates:
     - `data/interim/links/footnote_links.jsonl`: 7,307 distinct (span, hadith) pairs, sorted by `(span_id, hadith_id)`.
     - `data/interim/links/footnote_refs_unlinked.jsonl`: 1,370 unlinked references (reasons: 409 `not_in_sources`, 45 `not_found`, 916 `unattached`).
2. **Graph loader (`src/graph/hadith_links.py`):**
   - Implemented `write_cites(driver, path)`:
     - Validates input file exists and is non-empty.
     - Validates that all referenced `Span` and `Hadith` nodes exist in Neo4j (refuses with error if any missing; 0 found missing).
     - Deletes existing footnote `CITES` edges from HADITH spans with provenance `source: "run:...-footnote-links"` and `method: "regex"` before reload (keeping the write idempotent).
     - Does not touch `CITES` from QURAN spans.
     - Writes in UNWIND batches with MERGE setting `evidence` (list of footnote span IDs), `ref_text` (list of citation texts), `number_kind`, `outcome: "auto"`, `method: "regex"`, `confidence: 0.95`, `source`, and `text_sim`.
3. **Task runner (`scripts/tasks.py`):**
   - Added `links` command:
     `python scripts/tasks.py links` builds JSONL files and prints the summary table.
     `python scripts/tasks.py links --write` writes to Neo4j (reserved for Claude post-approval; not executed by agy).
4. **Tests (`tests/test_hadith_links.py`):**
   - 11 tests verifying:
     - All 14 reference forms in the Facts table.
     - Multi-number forms (`وبرقم (...)` and `برقم (٦٩، ٧٠)`).
     - Kubra is never classified as `nasai`.
     - Word boundary enforcement («للبخاري» yields no reference).
     - Owner rule for inside, inside through QURAN parent, after with punctuation, and word between (returns None).
     - Muslim 2865 resolves to all 4 narrations (`2865.01`–`2865.04`), including `muslim:7207`.
     - Pinned exact build totals (7,307 links, 1,370 unlinked, 2,889 spans, 5,165 hadith nodes, per-collection pair counts).
     - Writer fixture test on `test:` spans and `test-coll:*` hadith testing validation, property persistence, idempotency on duplicate run, and complete fixture cleanup.
5. **Documentation:**
   - `docs/schema.md`: Updated `CITES` (Span→Hadith) specification to list `evidence` as a list of footnote span IDs, and added `ref_text`, `number_kind`, `outcome`, `text_sim`.
   - `docs/decisions.md`: Recorded T5.2 dated decision with Decision D1 and all measured counts.
