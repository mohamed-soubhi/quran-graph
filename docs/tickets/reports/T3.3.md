## What Changed

1. **`src/ingest/buckwalter.py`**:
   - Implemented extended Buckwalter transliteration table from official specification (`https://corpus.quran.com/java/buckwalter.jsp`).
   - `to_arabic(s: str) -> str`: Converts Buckwalter transliteration into Arabic script; raises `ValueError` on unmapped characters.
   - `to_buckwalter(s: str) -> str`: Converts Arabic script into Buckwalter transliteration; raises `ValueError` on unmapped characters.
   - `split_lemma(lem: str) -> tuple[str, int | None]`: Splits base lemma and homonym sense digit (e.g. `'EaAd2'` → `('EaAd', 2)`).

2. **`src/ingest/quranic_corpus.py`**:
   - Implemented `parse_corpus(zip_path, output_dir)` reading `data/raw/quranic-corpus/quranic-corpus-morphology-0.4.zip` in-place using `zipfile` (Hard Rule 5).
   - Generates deterministic, sorted UTF-8 JSONL datasets in `data/interim/corpus/` with sorted keys and LF line endings:
     - `words.jsonl`: 77,429 words (`word_id`, `ayah_id`, `position`, `text`, `bw`, `pos`).
     - `lemmas.jsonl`: 4,832 lemmas (`lemma_id`, `text`, `sense`, `bw`).
     - `roots.jsonl`: 1,642 roots (`root_id`, `text`, `bw`).
     - `word_lemmas.jsonl` (and `word_lemma.jsonl`): 74,608 links (`word_id`, `lemma_id`, `segment`).
     - `word_roots.jsonl` (and `word_root.jsonl`): 49,968 links (`word_id`, `root_id`).
     - `lemma_roots.jsonl` (and `lemma_root.jsonl`): 4,657 links (`lemma_id`, `root_id`).

3. **`scripts/tasks.py`**:
   - Added `"src/ingest/quranic_corpus.py"` to the `run_parse()` parser sequence for `python scripts/tasks.py parse`.

4. **`tests/test_parse_corpus.py`**:
   - `test_buckwalter_round_trip_and_errors`: Verifies lossless round trip on all 1,642 roots, 4,817 lemma texts, and 12,205 forms (0 unmapped characters); checks root `smw` -> `سمو`; checks `ValueError` on unknown characters; checks `split_lemma`.
   - `test_parse_corpus_counts_and_structure`: Verifies 77,429 words (1:1:1 text `«بِسْمِ»`, pos `N`), 4,832 lemmas (15 with sense, 4,817 distinct texts), 1,642 roots, 74,608 word→lemma links (486 words with 2), 49,968 word→root links (1 word with 2: 20:94:2), 4,657 lemma→root links (0 with >1 root, 175 lemmas without root).
   - `test_word_count_per_ayah_vs_t32`: Compares word counts against T3.2 `data/interim/quran/ayat.jsonl` and confirms exact equality except 2:181 (13 vs 14), 8:6 (11 vs 12), 13:37 (19 vs 20), 37:130 (3 vs 4).
   - `test_byte_identical_rerun`: Verifies rerun produces byte-identical files.
   - `test_tasks_parse_target`: Verifies `python scripts/tasks.py parse` executes successfully.

5. **`docs/decisions.md` & `docs/tickets/TRACKER.md`**:
   - Recorded exact T3.3 parser counts and metrics in `docs/decisions.md`.
   - Updated `docs/tickets/TRACKER.md` row `T3.3` to `review` with summary notes.
