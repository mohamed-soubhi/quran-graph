## What Changed
1. **`src/extract/quran_spans.py`**:
   - `find_quotes(text: str) -> list[tuple[int, int]]`: regex `﴿[^﴾]*﴾`, character offsets in original verbatim text, end exclusive, brackets included.
   - `parse_ref(text_after: str) -> dict | None`: parses `[سورة: آية]`, strips stray digits in surah names, handles single ayat and ranges, validates ayah number against surah `ayah_count`.
   - `match_quote(quote: str, covers: list[str], ref: dict | None = None) -> tuple[list[str], str, float]`: tokenizes normalized quote without inner `[[…]]`, matches against simple Quran token stream following preference order 1–5.
   - `extract_quran_spans(...) -> Path`: generates `data/interim/spans/quran.jsonl` with deterministic segment and start ordering.
   - CLI entry point with arguments (`--segments`, `--output`, `--source`).

   - Added `write_ayah_links(links, driver, session, batch_size)`: UNWIND batches merging `(Span)-[:EXPLAINS|CITES]->(Ayah)` setting provenance (`source`, `method`, `confidence`, `ref_text`).
