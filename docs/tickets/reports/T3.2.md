## What Changed

1. **`src/ingest/parse_quran.py`**:
   - Implemented `parse_surahs(metadata_path)` using `src.ingest.tanzil_metadata.read_suras`.
     - Generates 114 records ordered by `surah_id` (1..114).
     - Keys: `surah_id, name, tname, type, revelation_order, ayah_count, has_basmala` (false only for 9).
   - Implemented `parse_ayat(uthmani_path, simple_path)`:
     - Extracts ayat from `data/raw/tanzil/quran-uthmani.txt` and `quran-simple-clean.txt`.
     - Basmala rule (schema Q1): for ayah 1 of every surah except 1 and 9, compares the first 4 words using `normalize_with_map` against the 4 words of 1:1 (`['بسم', 'الله', 'الرحمن', 'الرحيم']`); drops them when matching.
     - Sets `text_norm = normalize_with_map(text_simple)[0]` and `word_count = len(text.split())` after basmala rule.
     - Keys: `ayah_id, number, surah_id, text, text_norm, text_simple, word_count`.
   - Implemented `parse_quran(output_dir, ...)`:
     - Writes UTF-8 JSONL to `data/interim/quran/surahs.jsonl` (114 lines) and `ayat.jsonl` (6,236 lines).
     - Deterministic output: `ensure_ascii=False`, keys sorted, explicit LF line endings.
   - CLI `main()` entrypoint.

2. **`scripts/tasks.py`**:
   - Added `run_parse()` and `"parse": run_parse` target to run Phase 3 parsers (`src/ingest/parse_quran.py`).

3. **`tests/test_parse_quran.py`**:
   - `test_parse_quran_counts_and_structure`: Exactly 114 surahs and 6,236 ayat; validates keys, ordering, types, and `has_basmala`.
   - `test_basmala_rule_and_differing_counts`: Exactly 112 ayat differ from raw (in both Uthmani and Simple-Clean); 1:1 and 9:1 equal raw verbatim; 112:1 normalized = `قل هو الله احد`.
   - `test_total_word_count`: Sum of `word_count` across all ayat = 77,433 (77,881 − 448).
   - `test_byte_identical_rerun`: Two consecutive runs generate byte-identical files.
   - `test_tasks_parse_target`: `python scripts/tasks.py parse` succeeds.

4. **Documentation & Tracking**:
   - `docs/decisions.md`: Recorded T3.2 parser counts, basmala rule details, and verification metrics.
   - `docs/tickets/TRACKER.md`: Updated `T3.2` status to `review` with notes.
