## What Changed

1. **`src/ingest/download.py`**:
   - Added `TANZIL_METADATA_URL = "https://tanzil.net/res/text/metadata/quran-data.xml"`.
   - Added `download_tanzil_metadata(dest_path, timeout, checksums_path)` helper reusing `fetch()` to download and append checksum.
   - Downloaded `https://tanzil.net/res/text/metadata/quran-data.xml` to `data/raw/tanzil/quran-data.xml` (verbatim 77,234 bytes).

2. **`data/raw/CHECKSUMS.txt`**:
   - Appended line for `data/raw/tanzil/quran-data.xml` with SHA-256 `8867c1d88191472adec9db694b3cd9f135b1a2ef580574d32cf888dcb22c5c7a`, URL `https://tanzil.net/res/text/metadata/quran-data.xml`, and date `2026-11-03`.

3. **`src/ingest/tanzil_metadata.py`**:
   - Implemented `read_suras(path) -> list[dict]` parsing `quran-data.xml` via `xml.etree.ElementTree` with `encoding="utf-8"`.
   - Returns list of 114 dictionaries containing keys:
     - `index`: int (1..114)
     - `ayas`: int
     - `start`: int
     - `name`: str (Arabic name)
     - `tname`: str (transliterated name)
     - `ename`: str (English name)
     - `type`: str ("Meccan" or "Medinan")
     - `order`: int
     - `rukus`: int

4. **`tests/test_tanzil_metadata.py`**:
   - Added `test_tanzil_metadata_checksum`: skips if absent; validates SHA-256 against `CHECKSUMS.txt`.
   - Added `test_tanzil_metadata_suras`:
     - Verifies exactly 114 suras with indices 1..114.
     - Verifies types of all fields (integers parsed as int).
     - Verifies total ayas = 6,236.
     - Verifies each surah's `ayas` matches ayah count from `data/raw/tanzil/quran-uthmani.txt`.
     - Verifies continuous start offsets (`start` of surah n+1 = start + ayas of surah n, starting at 0).
     - Verifies names: surah 1 = «الفاتحة», surah 2 = «البقرة», surah 30 = «الروم».
     - Verifies revelation types: exactly 86 Meccan and 28 Medinan.

5. **Documentation**:
