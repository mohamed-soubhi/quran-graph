# T0.6 Report — Conventions in code (logging and smoke target)

**Date:** 2026-10-31  
**Status:** review  

## What Changed
1. **`src/log.py`**:
   - Implemented standard logging utility `get_logger(name, level=logging.INFO)` returning a configured logger.
   - Configures `FileHandler` logging to `logs/<name>.log` (UTF-8 encoded) and `StreamHandler` outputting to console `sys.stdout`.
   - Prevents duplicate handlers on re-entry and disables propagation to avoid duplicate root logs.
2. **`src/graph/client.py`**:
   - Integrated `logger = get_logger("client")`.
   - Logs successful Neo4j connections and logs error on connection failures.
3. **`src/extract/glm_client.py`**:
   - Replaced custom logger configuration with `logger = get_logger("glm_client")`.
4. **`scripts/extract_smoke.py`**:
   - Added `--runs N` CLI argument using `argparse` (defaults to 5 if unspecified).
5. **`scripts/tasks.py`**:
   - Implemented `run_smoke`: runs `tests/test_neo4j.py` then `scripts/extract_smoke.py --runs 1` (fast execution).
6. **`tests/test_log.py`**:
   - Added unit tests checking logger creation, handlers, UTF-8 log file output (including Arabic characters), and idempotency.
