## What Changed
1. **`src/graph/load.py`**:
   - Implemented graph loader for L0 (Text: Quran, Corpus morphology) and L1 (Tafsir: Ibn Kathir).
   - Applies schema constraints and indexes first via `apply_schema(driver)` (T2.2).
   - Batches rows using `UNWIND` (batch size ≤ 5,000) and `MERGE` on unique constraint keys.
   - Sets provenance metadata on every relationship: `source` (`tanzil-1.1`, `quranic-corpus-0.4`, `spa5k@eb82bb6`), `method: 'dataset'`, `confidence: 1.0`.
   - Supports `--surah N` filtering for incremental surah loading as well as full-database loading.
   - Manages consecutive order relationships:
     - `NEXT` between Ayah nodes (1:1 -> 1:2 ... 114:6, across surahs).
     - `NEXT` between TafsirSegment nodes (in book order).
   - Logs complete node counts per label and relationship counts per type.

2. **`scripts/tasks.py`**:
   - Added `load` task supporting optional `--surah N` argument:
     `python scripts/tasks.py load [--surah N]`

3. **`tests/test_load.py`**:
   - Added automated tests verifying Surah 1 exact counts: 1 Surah, 7 Ayah, 29 Word, 7 COVERS.
   - Tests idempotency by executing consecutive loads on Surah 1 and asserting exact count equality.
   - Verifies provenance properties on all relationships in the graph.
