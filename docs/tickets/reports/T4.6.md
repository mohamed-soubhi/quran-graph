## What changed
1. **`src/extract/poetry.py`:**
   - Implemented pure functions `is_verse_line`, `extract_poetry_from_text`, and pipeline `extract_poetry`.
   - Filters lines by removing `[[…]]` footnotes and diacritics (U+064B–U+0652, U+0670), stripping spaces, verifying `' ... ' in cleaned` or `cleaned.endswith(' ...')`, with `len(cleaned) <= 100`.
   - Groups consecutive verse lines separated only by whitespace into single poems.
   - Trims backward from the poem end: trailing whitespace, then trailing `[[…]]` footnotes and preceding whitespace.
   - Skips verse lines inside footnote spans.
   - Writes `data/interim/spans/poetry.jsonl` (351 spans).

2. **`src/extract/structure.py`:**
   - Implemented `check_partial_overlaps`: asserts 0 partial overlaps across all spans (raises ValueError with span IDs on any partial overlap).
   - Implemented `find_parent_for_span` and `build_parents`: assigns each nested span its smallest enclosing span (minimum `end - start`; tie-breaker order HADITH > QURAN > OTHER > FOOTNOTE).
   - Writes `data/interim/spans/parents.jsonl` (12,855 rows).
   - Implemented `build_commentary`: partitions every segment into top-level spans and gaps; fills every gap and tail with a `COMMENTARY` span, tagging `blank: true` when containing no letter (`str.isalpha()` false on all chars).
   - Writes `data/interim/spans/commentary.jsonl` (58,584 spans).
   - Implemented `load_structure_to_neo4j`: removes old `COMMENTARY` and `OTHER` spans first, writes `OTHER` spans (with `lines`), writes `COMMENTARY` spans (with `blank`), and writes `INSIDE` edges (with `source`, `method`, `confidence`). Idempotent.

3. **`src/graph/spans.py`:**
   - Updated `merge_span_query` in `write_spans` to store optional properties `s.blank = row.blank` and `s.lines = row.lines`.
   - Added `write_inside_edges` helper for idempotent batch MERGE of `INSIDE` relationships with full provenance (`source`, `method`, `confidence`).

4. **`scripts/gate_4c.py`:**
   - Pure Python verification script (no Neo4j).
   - Verifies 100% exact character coverage (13,401,179 characters across 1,911 segments), touching spans, 0 holes, 0 overlaps.
   - Verifies 0 partial overlaps anywhere across all spans.
   - Verifies all nested spans lie strictly inside parent, and sibling children do not overlap.
   - Verifies gold OTHER spans (4/4 exact) and gold parent agreement (19/19 both-present / 29 total).

5. **`scripts/tasks.py`:**
   - Added target `structure`: runs `tasks.py structure` (steps 1–4) and `tasks.py structure --write` (steps 1–5).

6. **`tests/test_structure.py`:**
   - 11 unit tests covering verse rules, trailing footnote trimming, 150-char prose rejection, multiline poem grouping, footnote containment, parent smallest container rule, partial overlap exception, commentary gap filling and blank detection, whole-segment commentary for empty segments, gate 4c fixture passing and failing on 1-char hole, and Neo4j test-span-only writer test.

7. **Documentation:**
   - `docs/schema.md`: documented `blank` on COMMENTARY, `lines` on OTHER.
   - `docs/decisions.md`: added 2026-11-17 decisions entry.
   - `docs/tickets/TRACKER.md`: updated T4.6 to `review`.

   - It also checks that every nested span lies fully inside its parent, and that the gold examples match.
